# 実機検証手順

この文書は手順書であり、未実施の操作を合格として記録しない。特に実プレイヤー2人の接続、Golden Wheat による操作、再ログイン・chunk再ロードは実機で確認する。

## 自動テストとの区別

`src/test` の専用modは、実際のNeoForgeサーバーと依存modをロードし、Mixin適用後のターゲット選択・継続判定・キュー整理・ロケットの範囲判定/追尾/着弾を検証する。実際のNine Tails、wolf、タレット、ロケットを生成し、非ペットの判定は元のLTXI validatorと比較する。手持ちロケットへの非適用も検証する。

自動テストのテイム状態はPetting保存値をテストコードから設定し、所有者はFakePlayerまたは未解決UUIDで再現する。Golden Wheat操作、実プレイヤーのオンライン状態、永続化の往復、実際のアップグレード装着、通常tickによる探索から射撃までの一連の操作を代替しない。以下の手動試験でこれらを補う。

## 準備

1. Minecraft 26.1.2 / NeoForge 26.1.2.71、README指定の4modと本modだけを入れた検証用ワールドを作成する。本番ワールドは使用しない。
2. 同じ構成から本modだけを除いた比較用ワールドを用意する。Vanilla ペットと非ペットの挙動比較に使う。
3. プレイヤーAが Ionos を設置し、十分なエネルギーを供給する。射程内かつ視線が通る位置に Nine Tails を1体ずつ配置する。攻撃が成立することを野生個体で先に確認する。昼夜・難易度・射程・アップグレードは比較中に変えない。
4. Petting の Golden Wheat を使って実際にテイムする。UUID を付けるだけの模擬テイムはしない。Petting の所有者とテイム状態をUIまたは保存データで確認する。
5. 発射、対象への照準、HP、キュー表示、消費エネルギーを観察する。各試験は少なくとも探索・チャージ・発射サイクルを2回待つ。

## 必須ケース

| ケース | 操作 | 期待結果 |
| --- | --- | --- |
| 1 野生 | 野生 Nine Tails を Ionos 前に置く | 既存条件を満たせば選択・攻撃される |
| 2 同一所有者 | A が Nine Tails をテイム | 対象選択・直接攻撃しない |
| 3 異なる所有者 | B がテイム、A のタレット前に置く | 所有者不一致でも保護される |
| 4 別のオンライン所有者 | B を接続したままケース3を継続 | 保護される |
| 5 オフライン所有者 | B が退出、A はタレットのchunkをロード | 保護される |
| 6 Vanilla | 野生・A所有・B所有のwolfで比較 | 本modなしの LTXI の結果と同一（Petting未テイム） |
| 7 Extermination | Engagement Protocol を変更し野生・ペットを比較 | 野生は従来どおり、Pettingペットは除外 |
| 8 再ロード | 保存・再ログイン、全員が遠方へ移動してchunkアンロード後に戻る。サーバー再起動も実施 | テイム状態と保護が維持される |
| 9 選択後テイム | ターゲット選択後・発射前にGolden Wheatでテイム | 次のサーバーtickで除外、発射しない |
| 10 Arcキュー | 複数の野生対象を取得させ、副対象だけをテイム | 次tickで副対象をキューから除外、主対象への攻撃時にも副対象を攻撃しない |
| 11 テイム解除 | Pettingで解除できる場合、解除して再探索 | 元のLTXI条件を満たせば再び対象となる |
| 12 Atmos範囲 | 野生対象の近くにペットを置き着弾させる | 野生は従来どおり、ペットは範囲対象から除外されHPが減らない |
| 13 飛翔中テイム | Atmos発射後、着弾前に対象をテイムする | 次tickで追尾解除、直接・範囲ダメージなし |
| 14 発射元撤去 | ケース13で発射後にタレットも撤去する | ペット保護が維持される |

ケース1～10を Atmos と Noctis でも実施する（Arc副対象試験はIonosのみ）。All Entities / Neutral Enemy / Hostile Only の各モードで、Pettingペットの除外と、非ペットの比較ワールドと同じ挙動を確認する。各モードの対象種別差は LTXI 本来の仕様に従う。

ケース9と13では発射前と発射後を区別する。発射済みロケットは消去されないが、テイム済み対象の追尾を解除し、着弾してもペットにダメージを与えないことを確認する。手持ち武器のロケットは比較用ワールドと同じ結果であることも確認する。

## ロードと配布

- 完成jarに依存modや検証用クラスが同梱されていないことを確認する。
- LTXI または Petting を外すと、明示的な依存関係エラーで起動を拒否することを確認する。
- 指定版でサーバー・クライアントを起動し、Mixin適用エラーがないことを確認する。
- 結果を記録する際は、各modのバージョン、タレット/モード、所有者状態、実施した操作、期待値、実測結果を併記する。
